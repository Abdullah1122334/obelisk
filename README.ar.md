## لماذا أوبيليسك

المسلّة منحوتة من كتلة غرانيت واحدة، مُتوَّجة بالإلكتروم لتلتقط أول الضوء، وظلّت قائمة ثلاثة
آلاف وخمسمئة عام. وتلك هي أطروحة المنتج: **كتلة واحدة، دقيق، ولا يسقط.**

أربع دعاوى، وكل ما في هذا المستودع موجود لخدمة واحدة منها:

1. **يُشغّل برمجيات ويندوز بأقل احتكاك.** بادئة واين مُهيّأة مسبقًا وفيها الخطوط العربية
   مسجَّلة داخلها، ومعالجة لملفات `.exe` تعمل بنقرة مزدوجة، وجدول توافق أمين يخبرك بما
   **لا** يعمل.
2. **لا يمكن لتحديثٍ أن يكسره كسرًا دائمًا.** أحجام Btrfs الفرعية، ولقطة عند كل معاملة
   pacman، وكل لقطة مدخلٌ في GRUB. والتعافي لا يحتاج فضاء مستخدم عاملًا ولا توثيقًا: أعد
   الإقلاع واختر المدخل السابق.
3. **ثنائي اللغة بالكامل، دون أن تكون إحدى اللغتين ترجمةً للأخرى.** العربية والإنجليزية هما
   أول خيارين عند كل نقطة اختيار لغة، بدءًا من قائمة الإقلاع. مصدر حقيقة واحد لكل النصوص.
   وتبديل اللغة مِفتاح.
4. **يعمل جيدًا على عتادٍ يرفض ويندوز 11 التثبيت عليه.** ميزانية أداء مفروضة في CI لا
   مأمولة، ومقيسة على عتاد حقيقي لا مُقدَّرة.

## الأساس التقني

| | الاختيار | السبب |
|---|---|---|
| الأساس | آرتش لينكس، archiso | متدحرج: أحدث واين وMesa ونواة، وعليها يتوقف توافق ويندوز |
| سطح المكتب | كِيدي بلازما 6، وايلاند افتراضيًّا، وX11 متاح | أفضل دعم للاتجاه من اليمين لليسار، وأعمق تخصيص، وأخف من جنوم |
| المُثبِّت | كالاماريس | معياري وقابل للتنسيق. ملاحظة: **غير موجود في أي مستودع آرتش** — أوبيليسك يبنيه |
| نظام الملفات | Btrfs بأحجام فرعية وضغط zstd | شرط للقطات |
| النواة | `linux`، مع `linux-lts` احتياطيًّا في GRUB | `linux-zen` اختياري: يكلّف بطارية المحمول ولا يُفرَض أبدًا |
| الصوت | PipeWire و WirePlumber | زمن استجابة منخفض، ويعمل مع واين وبروتون |
| الشبكة | NetworkManager و systemd-resolved، وDNS عبر TLS | خصوصية افتراضية |
| التحديثات | آرتش، مثبَّتة على تأخير 7–14 يومًا | حماية من كسر الإصدار المتدحرج |

## البناء

أوبيليسك يُبنى بواسطة CI لا على محطة عمل — انظر القسم ٢ في
[docs/ARCHITECTURE.ar.md](docs/ARCHITECTURE.ar.md) لمعرفة لماذا هذا قرار تصميمي لا قصور.

```sh
cp config.env.example config.env    # اضبط OBELISK_ARCHIVE_DATE
sudo ./scripts/build-iso.sh
./scripts/test-qemu.sh              # يُقلِعها تحت BIOS و UEFI
```

على ويندوز، اقرأ [docs/BUILDING-ON-WINDOWS.ar.md](docs/BUILDING-ON-WINDOWS.ar.md) أولًا.
فيه خطوة إعداد واحدة أهم من كل ما عداها، وتخطّيها يُفسِد المشروع بصمت.

## تخطيط المستودع

| المسار | المحتوى |
|---|---|
| `design/` | `tokens.yaml`، مصدر الحقيقة الوحيد لكامل الشكل |
| `i18n/` | `en.json` و `ar.json`، مصدر الحقيقة الوحيد لكل النصوص |
| `iso/` | ملف archiso الشخصي: الحزم، وإعداد pacman، ونظام الملفات الحيّ |
| `packages/` | حزم أوبيليسك، كلها ببادئة `obelisk-` |
| `repo/` | بناء الحزم وتوقيعها ونشرها |
| `installer/` | إعداد كالاماريس وهويته — وليس نسخة مُشتقّة منه أبدًا |
| `scripts/` | أدوات البناء والاختبار والقياس والتدقيق |
| `docs/` | التوثيق. لكل ملف توأم بامتداد `.ar.md` |
